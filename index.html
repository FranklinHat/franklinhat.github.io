Homelab Discord Gateway

deployed on my home server

A lightweight Go service that turns alerts from my self-hosted Docker services into readable Discord notifications, so I know what's happening on my server without checking it.

Features

  • Receives alerts over HTTP and formats service status into clean Discord messages
  • Routes each alert to a different Discord channel by URL path using webhooks
  • 5-second request timeouts so a slow request never hangs the gateway
  • Packaged as a small container using a multi-stage Docker build

Challenges & Key Learnings

  • Picking Go up from scratch: learning its HTTP server, structs, and error-handling style
  • Learning why timeouts matter: one slow webhook call shouldn't block every other alert
  • Using multi-stage Docker builds to keep the final image small enough for low-power hardware

osu! PP Tracker

in progress

A Spring Boot backend that calculates the potential performance points (pp) a player could earn on an osu! beatmap, based on their actual hit results.

Features

  • Authenticates with the official osu! API using OAuth client credentials
  • Takes real 300 / 100 / 50 / miss counts to estimate pp for a play
  • Next up: containerizing it for my home server and adding JUnit tests

Challenges & Key Learnings

  • Learning Spring Boot for the first time: controllers, services, and dependency injection
  • Handling OAuth authentication and keeping API secrets out of the codebase
  • Replacing hardcoded test values with real user input, and seeing why tests matter as the logic grows
